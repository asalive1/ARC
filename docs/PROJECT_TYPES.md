# Project Types

## Generic

Purpose:
General purpose project.

Build Command:
None configured.

---

## Docker

Purpose:
Containerized applications.

Development Build:
docker compose up -d

Production Build:
docker compose up -d

---

## DotNet

Purpose:
.NET applications.

Development Build:
dotnet build

Production Build:
dotnet publish

---

## Node

Purpose:
Node.js / React applications.

Development Build:
npm run build

Production Build:
npm run build

---

## Python

Purpose:
Python applications.

Development Build:
python main.py

Production Build:
python main.py

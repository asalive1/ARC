# ARC Product Roadmap

Phase 1 implementation is in place, with external acceptance still outstanding.
Routing expansion is the next implementation phase; no product phase is
complete yet.

See [the delivery plan](delivery-plan.md) for phase scope, gates, validation,
and release workflow.

## Proposed phases

0. Architecture and contracts
1. ALSA/RTP-to-RTP/SRT stateful audio slice and local worker
2. Routing matrix, fan-out, explicit replacement, immediate/Take workflows, and route presets; locks, concurrency, granular permissions, and undo/rollback are deferred
3. Zephyr Connect adapter and synthetic simulator
4. Network transport expansion and platform adapters
5. Signals, GPIO, Device Server integration, and automation
6. Hardening, recovery, backup/restore, portability, and acceptance
